# 匿名ランキングの設定手順（委員会・先生向け）

アプリの「百問繚乱」タブにある「みんなの中での位置（匿名）」を使えるようにする手順です。
設定するまでは「準備中」と表示され、どこにもつながりません。

## 先に決めること

- [ ] 先生（顧問・情報担当）の許可をもらう
- [ ] 学校のGoogleアカウントのドメイン（メールアドレスの @ の後ろ）を確かめる　**要確認**
- [ ] Firebase のプロジェクトを持つ人（管理者）を決める。できれば学校のアカウントで作る

## 手順

1. https://console.firebase.google.com/ でプロジェクトを作る（無料の Spark プランで足ります。Google アナリティクスはオフ）
2. **Authentication** → ログイン方法 → **Google** を有効にする
   - 設定 → 承認済みドメイン に `seg1gpt0jpn.github.io` を追加する
3. **Firestore Database** を作る（ロケーション：`asia-northeast1`（東京）、本番環境モード）
4. **ルール**：このリポジトリの `firestore.rules` を開き、`'SCHOOL_DOMAIN'` を学校のドメインに書き換えて、Firebase コンソールのルール画面に貼り付けて「公開」する
5. **プロジェクトの設定** → マイアプリ → ウェブアプリを追加し、表示された `firebaseConfig` の値を `lib/firebase_config.dart` に入れる。`schoolDomain` にも同じドメインを入れる
   - これらの値はWebページに必ず含まれる公開用の値なので、リポジトリに入れて問題ありません（守りはルールで行います）
6. `main` に push すると、自動でサイトが更新されます

## 仕組みと、守られること

| 保存されるもの | 誰が見られるか |
|---|---|
| `entries/{試験}/users/{uid}`：その人の区間（5%ごと）だけ | 本人だけ |
| `hist/{試験}`：区間ごとの人数 | 学校アカウントの人。ただし参加者が20人以上になってから |

- 点数そのもの・名前・メールアドレスは保存しません（ルールで区間以外を保存できないようにしています）
- 1人1つの試験・科目につき1件だけです。人数を水増ししたり、他人の分を書き換えたりはできません
- 学校外のアカウントは、読むことも書くこともできません
- ルールが正しく動くことは `firestore_test/` の自動テストで、push のたびに確かめています

## 管理者が守ること

Firebase の管理画面では、技術的には「どのアカウント（uid）がどの区間か」を調べられます。

- 管理者は `entries` の中身を見ない
- 管理者を増やさない（委員会の担当者1〜2人と顧問の先生だけ）
- 問題があったときは、`entries` と `hist` をまとめて削除してリセットする
